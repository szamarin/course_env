# Module 00 — Welcome: Lesson 01 Intro

## Overview
This starter lab verifies that your Python environment, `uv`, `marimo`, and the shared `course_utils` package are properly installed and working.

## Objectives
1. Verify package versions (`marimo`, `polars`, `pandas`, `numpy`, `altair`).
2. Load lesson-local data from `assets/sample_dataset.csv` using `course_utils.get_asset_path`.
3. Interact with reactive marimo UI controls (`mo.ui.dropdown`, `mo.ui.slider`) and inspect real-time chart updates.

## Running This Lab

From the repository root:

```bash
uv run lab 00_welcome
```

Or open the notebook directly with `marimo`:

```bash
uv run marimo edit modules/00_welcome/lesson_01_intro/notebook.py
```
